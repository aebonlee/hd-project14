사용 안내

실제로 쓰는 순서

엑셀 준비 → 검증 → 확인 → 포털 입력 → 사람이 저장. 마지막 단계는 일부러 자동화하지 않았습니다.

1. 엑셀 준비

열 이름은 아래 중 아무거나 됩니다. 순서는 상관없고, 위에 제목이 몇 줄 있어도 찾아냅니다.

항목알아보는 이름
이름이름 · 성명 · 담당자 · Name · Full Name
국가국가 · 국가코드 · Country · Country Code
언어언어 · 사용언어 · Language · Locale
이메일이메일 · 메일주소 · Email · E-mail
딜러사명딜러사명 · 업체명 · 회사명 · Dealer Name · Company
전화번호전화번호 · 연락처 · Phone · Tel · Mobile
국가는 코드(KR)로 적어도 되고 한글 이름(대한민국)으로 적어도 됩니다. 다만 권한 매핑에 없는 국가는 받지 않습니다 — 아래 3번을 보세요.

2. 검증 결과 읽기

「검토필요」에 적힌 것은 포털에 넣기 전에 고쳐야 할 것입니다. 이 도구는 대신 고쳐 주지 않습니다.

나오는 말뜻어떻게
이름 없음 · 언어 없음 …필수 항목이 비어 있음엑셀에서 채우고 다시 올립니다
이메일에 공백이 있음포털이 받지 않습니다공백을 지웁니다
이메일에 한글이 있음같은 이유영문 주소로 바꿉니다
국가를 알 수 없음권한 매핑에 없는 국가3번 — 매핑에 추가합니다
이메일 중복같은 주소가 두 번 나옴한 줄을 지웁니다. 넣으면 중복 계정이 생깁니다
매핑에 빠진 항목그 국가의 권한 다섯 개 중 일부가 비어 있음3번 — 매핑을 채웁니다

3. 국가·권한 매핑 고치기

config/permissions.json 하나만 고칩니다. 코드는 손대지 않습니다.

"AE": {
  "name": "아랍에미리트",
  "dealernet": "조회+등록",
  "parts":     "조회+등록",
  "ordering":  "조회",
  "mydevelon": "조회",
  "irw":       "조회"
}

등급은 없음 · 조회 · 조회+등록 · 관리자 네 가지뿐입니다. 그 밖의 말을 적으면 검증에서 걸립니다 — 오타로 권한이 잘못 나가는 것을 막기 위해서입니다.

모르는 국가에 기본 권한을 주지 않습니다. 조용히 기본값을 주면 잘못된 권한이 나가도 아무도 모릅니다. 표에 추가하도록 막아 세웁니다.

4. 포털 입력

검증을 통과한 줄만 담은 JSON 을 내려받아 씁니다.

export HD_PORTAL_USER='사번 또는 아이디'
export HD_PORTAL_PASS='비밀번호'
node scripts/portal-fill.mjs 딜러등록_20260826.json
먼저 확인할 것 두 가지
① 로그인 자동화가 사내에서 허용되는지. 금지하는 곳이 많고 계정 잠금으로 이어질 수 있습니다.
② 포털이 등록 API 를 직접 받는지. 받는다면 화면을 흉내 내는 것보다 훨씬 안정적입니다 (화면은 개편되면 바로 깨집니다).

아직 채워야 하는 부분

포털 화면의 입력칸 이름(선택자)이 필요합니다. 사이트가 사외에서만 열리고 로그인해야 볼 수 있어 비워 두었습니다. 비어 있으면 스크립트가 스스로 멈춥니다 — 엉뚱한 곳에 입력하지 않도록.

  1. 포털에 로그인해 신규 딜러 등록 화면을 엽니다.
  2. 입력칸에서 우클릭 → 검사를 눌러 id 나 name 을 확인합니다.
  3. scripts/portal-fill.mjs 의 SELECTORS 에 #id 또는 [name="..."] 형태로 적습니다.
  4. 한 명만 먼저 돌려 보고, 화면에 제대로 들어가는지 확인한 뒤 나머지를 진행합니다.

5. 저장은 사람이

스크립트는 프로필과 권한을 입력만 하고 멈춥니다. 화면에서 확인한 뒤 직접 Save 를 누르고, Enter 를 치면 다음 딜러로 넘어갑니다. 기획서의 「검토 알림」 요구를 그대로 지킨 것입니다 — 자동으로 저장해 버리면 잘못 들어간 것을 되돌리기가 훨씬 번거롭습니다.

계정 정보 다루기

아이디·비밀번호를 코드나 엑셀에 적지 마세요. .env 로만 받고 그 파일은 커밋되지 않습니다(.gitignore).
한 번 커밋한 비밀번호는 지워도 커밋 기록에 남습니다. 실수로 올렸다면 비밀번호를 바꾸는 것 말고는 방법이 없습니다.

파일은 서버로 올라가지 않습니다

엑셀 읽기도 검증도 전부 이 브라우저 안에서 끝납니다. 딜러 개인정보(이름·이메일·전화번호)를 다루므로 이 점이 중요합니다.
