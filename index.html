신규 딜러 Access Portal 등록 자동화

딜러가 새로 생길 때마다 반복하던 PROFILE 등록 + AUTHORIZATION 설정을 줄입니다. 엑셀을 올리면 값을 검증하고 국가에 따라 권한 다섯 가지를 정해 줍니다.

1. 등록 요청 엑셀을 올리세요

필요한 열: 이름 · 국가 · 언어 · 이메일 · 딜러사명 · 전화번호 (영문 머리글도 알아봅니다)

    Template Download

    DealerNET User Registration 정식 템플릿입니다. Member of Dealer 열은 자동으로 채우지 않습니다 — 포털에서 딜러를 직접 검색해 고르는 항목입니다.

    국가별 권한 매핑

    아래 표가 정본입니다. config/permissions.json 을 고치면 바로 반영됩니다 — 코드는 손대지 않습니다. 담당자가 직접 관리하는 표입니다.

    매핑에 없는 국가는 기본값을 주지 않습니다. 조용히 기본 권한을 주면 잘못된 권한이 나가도 아무도 모릅니다. 그 국가를 표에 추가하도록 막아 세웁니다.

    포털에 넣는 것은 마지막 단계입니다

    이 화면은 넣기 전까지를 맡습니다. 표에서 넣을 줄을 체크해 내보내면, scripts/portal-fill.mjs(Playwright)가 입력칸을 채웁니다. 로그인과 최종 Save 는 사람이 합니다.

    로그인은 사람이 직접 합니다. 사내 정책상 로그인 자동화가 금지되어 있어 그 기능을 아예 만들지 않았습니다 — 이 도구는 아이디·비밀번호를 받지도, 저장하지도, 묻지도 않습니다.
    브라우저가 열리면 평소대로 로그인하시고, 그 뒤부터 스크립트가 입력칸을 채웁니다.
