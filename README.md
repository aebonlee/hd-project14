# 신규 딜러 Access Portal 등록 자동화

> 🌐 **[aebonlee.github.io/hd-project14](https://aebonlee.github.io/hd-project14/)** · 저장소: https://github.com/aebonlee/hd-project14
> 기획: **임나연** · 생성형 AI 업무자동화 전문가과정 1차수

딜러가 새로 생길 때마다 **PROFILE 등록 + AUTHORIZATION 설정**을 손으로 반복하던 일을 줄입니다.

## 무엇을 자동화하나

| 단계 | 지금 | 이 도구 |
|---|---|---|
| ① 딜러 정보 확인 | 엑셀을 눈으로 훑음 | **엑셀을 올리면 줄마다 검증** |
| ② 국가별 권한 결정 | 표를 보며 하나씩 고름 | **국가로 다섯 항목 자동 결정** |
| ③ 포털 입력 | 한 명씩 손으로 | Playwright 로 대신 입력 |
| ④ 최종 저장 | 사람 | **사람** (그대로 둡니다) |

④를 자동화하지 않은 이유는 기획서의 요구 그대로입니다 — *"최종 Save 전 검토 단계 필요"*.
포털에 잘못 들어간 뒤 되돌리는 것이 훨씬 번거롭습니다.

## 국가별 권한 매핑

`config/permissions.json` 하나가 정본입니다. **코드는 손대지 않습니다.**

```json
"KR": { "name": "대한민국", "dealernet": "관리자", "parts": "조회+등록",
        "ordering": "조회+등록", "mydevelon": "조회", "irw": "관리자" }
```

권한 항목 다섯 가지: DealerNET · Parts Catalog · Complete Ordering · My Develon · Inventory, Retails & Warranty
등급 네 가지: 없음 · 조회 · 조회+등록 · 관리자

> **매핑에 없는 국가는 기본값을 주지 않습니다.**
> 조용히 기본 권한을 주면 잘못된 권한이 나가도 아무도 모릅니다.
> 그 국가를 표에 추가하도록 막아 세웁니다. `test/logic.test.js` 가 이 규칙을 지킵니다.

## 넣기 전에 거르는 것

포털에 절반쯤 들어간 뒤 틀린 것을 발견하면 되돌리기가 번거롭습니다. 그래서 앞에서 잡습니다.

- 필수 항목 누락 (이름·국가·언어·이메일·딜러사명·전화번호)
- 포털이 받지 않을 이메일 — 공백, `@` 없음, 한글, 점 없는 도메인
- 알 수 없는 국가 → **권한을 지어내지 않고** 비웁니다
- **같은 이메일 중복** — 대소문자가 달라도 같은 주소로 봅니다. 놓치면 포털에 중복 계정이 생깁니다

전화번호는 넣으면 안 될 글자만 빼고 **자릿수는 건드리지 않습니다** — 나라마다 다릅니다.

## 포털 자동 입력

```bash
export HD_PORTAL_USER='...'      # 코드에 적지 않습니다
export HD_PORTAL_PASS='...'
node scripts/portal-fill.mjs 딜러등록_20260826.json
```

### ⚠ 아직 완성할 수 없는 부분

포털 화면의 **입력칸 이름(선택자)** 을 알아야 하는데, 사이트가 사외에서만 열리고
로그인해야 볼 수 있습니다. `scripts/portal-fill.mjs` 의 `SELECTORS` 가 비어 있고,
비어 있으면 스크립트가 **스스로 멈춥니다** — 엉뚱한 곳에 입력하지 않도록.

채우는 방법:
1. 포털에 로그인해 신규 등록 화면을 엽니다
2. 입력칸에서 우클릭 → 검사 → `id` 나 `name` 을 확인합니다
3. `SELECTORS` 의 해당 자리에 `#id` 또는 `[name="..."]` 형태로 적습니다

나머지 흐름(로그인 → 신규 → 프로필 입력 → 권한 탭 → 확인 대기)은 이미 되어 있습니다.

### 먼저 확인할 것

- **로그인 자동화가 사내에서 허용되는지.** 금지하는 곳이 많고 계정 잠금으로 이어질 수 있습니다.
- 포털이 SPA 인지, 등록 **API 를 직접 부를 수 있는지**. 부를 수 있다면 화면을 흉내 내는 것보다 훨씬 안정적입니다.
